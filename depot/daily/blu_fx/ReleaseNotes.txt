BLU-fx v2.0.0b2  (packaged on Thu Nov 19 2026)
===============================================================================

HIGHLIGHTS FOR THIS RELEASE (v2.0.0b2):

  * In-Simulator User Guide Window (ImGee v1.1.0 & ImgDocWindow):
    - Added a dedicated "User Guide Window" button directly in the Settings window
      footer (bottom right), making the complete illustrated manual instantly
      accessible right inside X-Plane without leaving the simulator or opening a PDF.
    - Features full 2-row document viewer chrome: zoom slider, table-of-contents
      navigation, transparency controls, and live hot-reloading.

  * Native ImGee GFM Alert Callout Cards:
    - User Guide now features native GitHub Flavored Markdown alert cards
      (> [!NOTE], > [!TIP], > [!IMPORTANT], > [!WARNING], > [!CAUTION]).
    - Each callout renders with dedicated theme-aware accents, backgrounds,
      and vector iconography powered by ImGee's procedural rendering engine.

  * Click-to-Enlarge Markdown Image Lightbox:
    - Clicking any User Guide illustration opens an in-context, aspect-fit
      zoom lightbox clamped directly to the window canvas.
    - Deepened dimmer overlay and dedicated high-contrast backing plates behind
      figure captions for crystal-clear readability over document text.
    - Robust release-dismissal hit-shielding: clicking anywhere outside the image
      or pressing Esc dismisses the lightbox cleanly without click-through loops.

  * Zero-Bias Procedural Vector Icons:
    - Completely eliminated Dear ImGui half-pixel line bias across all vector glyphs,
      ensuring perfectly symmetric, upright exclamation marks, dots, and a newly
      refined lightbulb silhouette.

  * UI & Tooltip Polish:
    - Full TimedTooltip click-to-toggle support across status indicators.
    - Active cursor affordances (Hand for links/triggers, ResizeNS for menus).

BLU-fx v2.0.0b1  (packaged on Mon Nov 16 2026)
===============================================================================

HIGHLIGHTS FOR THIS RELEASE (v2.0.0b1):

  * Modern ImGui User Interface:
    - Completely replaced legacy XPWidgets with a modern, dark-themed Dear ImGui
      interface powered by ImgWindow.
    - Crisp, proportional font rendering with full support for X-Plane UI Zoom,
      Retina, and high-DPI displays across macOS, Windows, and Linux.
    - Balanced, symmetric 7-boxel window bezels matching native simulator chrome.

  * Live Interactive Split-Screen Preview:
    - Instantly evaluate color grading adjustments side-by-side with raw simulator
      output before saving.
    - Draggable interactive curtain wipe divider with an optional high-contrast
      hairline indicator.
    - Momentary full-view hold button for rapid A/B visual comparisons.

  * Non-Destructive Preference Architecture:
    - User interface preferences (window positions, split preview state, curtain
      divider position) are now saved independently to Output/preferences/blu_fx.prf.
    - Your color grading settings remain pure in their respective profile .ini files
      without UI pollution.

  * Integrated In-Simulator User Guide:
    - Comprehensive user documentation accessible directly from the simulator menu
      (Plugins > BLU-fx > User Guide) and Settings window header.
    - Rich in-window markdown reader featuring high-resolution illustrated figures,
      smooth font zooming, and hot-reload support.
    - High-quality bundled PDF manual located in docs/BLUFX_User_Guide.pdf.

  * Dual-Simulator & Multiplatform Support:
    - Full native compatibility with X-Plane 12 (photometric atmospheric lighting)
      and X-Plane 11 (OpenGL, Vulkan, and Metal).
    - Automatically detects X-Plane 12 and cleanly hides legacy Rayleigh scattering
      and camera shaking overrides.
    - Triple-platform native 64-bit binaries: macOS universal (Apple Silicon arm64
      and Intel x86_64), Windows x64, and Linux x64.

  * Modern SkunkCrafts Updater v4 Integration:
    - Distributed across high-speed global CDN (GitHub Pages) with multi-channel
      support (release, beta, and daily).

  * Downgrade Safety & Legacy Mirroring:
    - Automatically updates a mirror of current color adjustments into the root
      blu_fx.ini file whenever adjustments or profiles are saved.
    - If you ever downgrade or switch back to v1.x, your latest color grading
      settings remain fully intact and immediately accessible.
    - Optional opt-out checkbox in Settings footer if you want to turn off
      legacy file updates completely.

HISTORICAL RELEASE NOTES:
===============================================================================

v1.2.3: (January, 2026)

  * Fix minor issues that might cause complaints in X-Plane v12.4.0, due
    to checks that X-Plane now does to ensure that plugins don't access
    XPLM features before their XPluginStart() function is called.
  * Move legacy startup checks to runtime to ensure strict XPLM compliance.
  * Intentionally ignore any attempts to modify the X-Plane 11 only feature
    "Cinema Verite" setting in newer XP12 versions.

v1.2.2:

  * Change the order of startup and shutdown of all OpenGL functionality
    based on the requirements for plugin uses in environments with modern
    graphics drivers (X-Plane v11.50+ in Vulkan/Metal mode, and X-Plane 12+).
  * Eliminate potential timing issues with early initialization and late
    teardown of OpenGL library calls.
  * Support dynamic disabling and re-enabling of BLU-fx from within the
    X-Plane Plugin Admin menu without restarting the simulator.

v1.2.1:

  * When the current configuration matches one of the presets displayed
    in the button array in the Settings window, disable that preset button
    so the user can easily tell which preset is currently loaded.
  * Help users recognize when a restored preset matches saved configuration.

v1.2.0:

  * Introduce support for X-Plane 11 and X-Plane 12 (64-bit only).
  * Provide quick restoration of the current filter configuration from the
    saved .prf / .ini file.
  * Support swapping the active .ini file and reloading on demand without
    restarting X-Plane.
  * Hide the Rayleigh slider in X-Plane 12, since Rayleigh scattering is
    handled natively by the new physical photometric atmosphere engine.
  * Fix window and font sizing for non-100% UI Zoom settings in X-Plane.
  * Add buttons to reload and save filter state on demand.

v1.1.0:

  * 64-bit release supporting modern X-Plane plugin formats (X-Plane 11.10+).
  * Drop support for legacy 32-bit operating systems and X-Plane 10.
  * Add Revert button to discard unsaved filter adjustments.

v1.0.0:

  * Original open-source post-processing color grading plugin created by
    Matteo Hausner.
